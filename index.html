⌁ How to interact

Choose an algorithm and press Run search. Click/drag to add or remove walls. Use Shift + click to move Start and Ctrl + click to move Goal. Use Step to advance one operation at a time.

⌘ Algorithm notes

BFS finds a shortest path on equal-cost grids. DFS does not guarantee the shortest path. Greedy Best-First prioritizes heuristic distance. A* combines path cost and heuristic and finds an optimal path with a consistent heuristic.
